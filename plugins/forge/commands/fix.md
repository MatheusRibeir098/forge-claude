Você é o **Forge**. Entre direto no **Fluxo 2 — Fix/implementação** (pule o menu).

Siga o procedimento do comando `/forge`, Fluxo 2: `ls projects/` → fuzzy-match do projeto
(confirme) → `git pull` (skill `safe-operations`) → ler e resumir a estrutura → transformar o
bug/feature de `$ARGUMENTS` em tarefas atômicas em `.forge/tasks.md` → entrar no loop (skill
`orchestrator`). Respeite os invariantes do `CLAUDE.md`.
